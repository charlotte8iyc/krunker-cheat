# krunker-cheat

Bookmarklet cheat untuk krunker.io — 11 fitur.

## Pakai

Buka krunker.io, jalan ke match, lalu klik bookmark ini:

```javascript
javascript:(function(){var s=document.createElement('script');s.src='https://raw.githack.com/charlotte8iyc/krunker-cheat/main/krunker.js';document.body.appendChild(s);})();
```

Menu muncul di kiri atas. Keyboard: angka 1-9 toggle cepat, Insert sembunyikan menu.
